# Anti-Fog V2 Strategy (2026-04-16 12:49:59)

## Problem
Current free-space constraint was mainly a loss term and did not directly control densify/prune decisions.
This allowed early-stage gaussian over-growth in far/free space and caused persistent fog-like artifacts.

## Implemented Changes

### 1) Free-space seed detection is now explicit in gaussian control
- Added `_compute_free_space_gaussian_mask()` in `models/gaussians/vanilla.py`.
- Mask condition: far from depth surface + low opacity, configurable by:
  - `free_space_seed_distance_min`
  - `free_space_seed_opacity_max`
  - `free_space_seed_only_bright`

### 2) Densify gate now blocks/throttles free-space growth
- Updated `_suppress_foggy_growth_candidates()`:
  - `free_space_split_block`: blocks split for free-space seeds.
  - `free_space_dup_keep_ratio`: only keep top-k free-space duplicates by gradient.
- This turns free-space from a pure loss signal into structural growth control.

### 3) Densify budget now enforces free-space cap + dynamic decay
- Updated `_apply_densify_budgets()`:
  - `free_space_new_points_ratio_cap`: cap free-space share of new points each refine step.
  - `dynamic_budget_from_floater_ratio`: if floater ratio is high, use a lower budget.
  - `floater_ratio_budget_trigger`
  - `dynamic_max_new_points_ratio_per_refine`

### 4) Early-stage growth guardrail
- Added early growth cap in `_apply_densify_budgets()`:
  - `bg_growth_cap_ratio_before_8k`
  - `bg_growth_cap_until_step`
- If total background points exceed cap before the target step, free-space densification is disabled.

### 5) Pruning priority now favors free-space cleanup
- Updated `adaptive_floater_pruning()` hard-prune priority score to include:
  - `free_space_priority_weight`
  - `free_space_priority_margin`
- Also stores runtime floater stats (`_last_floater_ratio`) for dynamic densify budgeting.

## Config Defaults Updated
File: `configs/omnire_extended_cam_lidar.yaml`

- Hard pruning made earlier/stronger:
  - `hard_prune_interval: 2000`
  - `max_prune_ratio_per_hard_step: 0.003`
  - `max_candidate_prune_ratio: 0.35`
- New free-space growth/prune controls added.
- Dynamic densify budget and early growth cap added.

## Expected Effect
- Reduce early free-space point explosion.
- Limit free-space share in new points per refine step.
- Improve cleanup speed for fog-like gaussian clusters.
- Keep bright-region control and existing anti-fog components compatible.
