# 混合策略改动记录（2026-04-16 17:03:17）

## 目标
落实“分阶段 + 分区域”的去雾策略：
- 前期：硬门控优先，尽量从源头阻断雾点产生。
- 中期：保留硬门控，同时允许有限细节恢复。
- 后期：适当放松门控，避免画面过硬、细节欠拟合。

## 修改文件
- `models/gaussians/vanilla.py`
- `configs/omnire_extended_cam_lidar.yaml`

## 代码侧改动

### 1) 新增通用阶段配置读取
在 `VanillaGaussians` 中新增：
- `_get_surface_schedule_stage_cfg(schedule_key)`
- `_get_fog_hard_gate_stage_cfg()`

作用：
- 读取并按 step 选择 `surface_guided_densification` 下的任意阶段表。
- 本次用于 `fog_hard_gate_schedule` 的分阶段硬门控。

### 2) split 硬门控增强（源头阻断）
函数：`_filter_split_candidates_by_surface()`

新增能力：
- 支持阶段化覆盖 `split_surface_distance_max`（分阶段最大表面距离）。
- 支持 `split_min_grad_scale`：梯度不足的 split seed 直接拒绝。

效果：
- 低置信、离表面远的 split 候选在生成前被拦截。

### 3) dup 硬门控增强（源头阻断）
函数：`dup_gaussians()`

新增能力：
- 支持阶段化覆盖 `dup_surface_distance_max`。

效果：
- 远离表面的 clone 候选直接拒绝，降低体积雾点复制。

### 4) fog candidate 抑制升级（分区域硬门控）
函数：`_suppress_foggy_growth_candidates()`

新增能力：
- 阶段化控制 `free_space_split_block`、`free_space_dup_keep_ratio`。
- 新增 `free_space_no_growth`：自由空间区域 split+dup 直接禁止。
- 新增 `bright_low_opacity_no_growth` + `bright_low_opacity_max`：亮区低opacity高风险点直接禁止增长。
- 新增 `fog_min_grad_scale`：对 foggy 区域弱梯度候选进行硬阻断。

效果：
- 由“限额/软抑制”升级为“高风险区域直接不让生”。
