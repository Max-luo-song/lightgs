## 修改摘要

### 1. 加强高亮区几何抑制

- `highlight_geometry_suppression.w: 0.03 -> 0.04`
- `highlight_geometry_suppression.rear_camera_extra_weight: 2.0 -> 2.5`

目的：

- 更强地阻止后视高亮区域用 opacity 堆几何去拟合亮斑，减少“发白空气层”。

### 2. 恢复并加强后视自由空间伪监督

- `free_space.rear_camera_weight: 1.5 -> 2.5`
- `free_space.rear_pseudo_weight: 0.1 -> 0.25`
- `free_space.rear_pseudo_grad_scale: 2.0 -> 1.5`

目的：

- 提高后视自由空间约束强度，让“深度前方不该有几何”的区域更难保留雾状高斯。
- 降低伪监督置信下限的保守程度，避免有效约束样本被过滤过多。

### 3. 延长白雾残留清理窗口

- `floater_detection.soft_prune_until: 8000 -> 14000`
- `floater_detection.floater_score_thresh: 0.85 -> 0.80`
- `floater_detection.max_soft_prune_ratio: 0.012 -> 0.02`
- `floater_detection.soft_opacity_shrink: 0.992 -> 0.990`
- `floater_detection.protect_high_grad_percentile: 0.90 -> 0.85`

目的：

- 让 soft pruning 在中后期继续工作，不让白雾在 8k 之后回生。
- 适度放宽 floater 判定与保护阈值，更愿意把低贡献雾层点识别并削弱掉。
