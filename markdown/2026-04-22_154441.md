# 2026-04-22 15:44:41 Three-Layer Light/Fog Strategy Update

## 目标

针对 `2026-04-22_114911` 版本中出现的现象：

- 后视空气雾状高斯有改善；
- 近处动态车辆车灯、灯条、车身高亮被过度抑制；
- 白色竖条 flare / bloom / 光晕没有恢复；
- Vehicle-Only 指标明显下降。

本次按三层分工更新实现：

```text
3DGS / PBR / emissive:
  负责车灯本体、车体表面、真实反射位置

camera flare module:
  负责竖条、光晕、bloom、传感器扩散

free-space / geometry suppression:
  继续禁止空气中长半透明雾状高斯
```

## 1. 可信高亮救回

修改位置：`models/trainers/base.py`

在 `rgb.saturation_aware_reweight` 下新增 `supported_highlight_rescue`：

- 对高亮像素继续计算 saturation confidence；
- 但如果高亮同时满足以下任一支持条件，则提高最低 confidence：
  - 位于 dynamic mask；
  - 有 lidar depth 支持；
  - 有明显图像边缘；
- 这样近处车灯、尾灯条、车辆边缘高亮不会被 `min_confidence` 直接压到近乎无监督。

配置入口：

```yaml
trainer.losses.rgb.saturation_aware_reweight.supported_highlight_rescue
```

## 2. 高亮亮度保底

修改位置：`models/trainers/base.py`

新增 `saturation_highlight_floor` loss：

```text
只对 supported highlight 启用；
不要求逐像素拟合过饱和值；
只要求 pred_luma 达到一个保守下限。
```

目标是让真实灯芯和灯条不要消失，同时避免恢复成靠 opacity/scale 堆出来的雾。

配置入口：

```yaml
trainer.losses.rgb.saturation_aware_reweight.highlight_floor
```

默认目标：

```text
target_luma = clamp(0.70 * gt_luma, min=0.45, max=0.85)
```

## 3. Camera-Space Flare

修改位置：`models/trainers/scene_graph.py`

新增 `camera_flare` 后处理：

```text
world_rgb = affine(rgb_gaussians + sky)
rgb_flare = camera_flare(world_rgb)
rgb = clamp(world_rgb + rgb_flare)
```

flare 只由预测的高亮 core 触发：

- vertical streak kernel：恢复白色/红色竖条；
- local bloom kernel：恢复灯周围 bloom / halo；
- 只对配置中的后视/强 flare 相机启用。

关键安全点：

```text
flare_source = world_rgb.detach()
```

因此 flare 可以进入最终图像，但不会通过竖条卷积反向推动 3D 几何、opacity、scale 或 densify。

输出新增：

- `outputs["rgb_world"]`
- `outputs["rgb_flare"]`
- `outputs["rgb"] = rgb_world + rgb_flare`

配置入口：

```yaml
trainer.render.camera_flare
```

## 4. 几何安全层对齐

修改位置：`models/gaussians/vanilla.py`

新增 `supported_highlight_geometry`：

- surface-supported bright Gaussian：
  - 允许贴表面 split refinement；
  - 禁止 duplicate diffusion；
- unsupported / free-space bright Gaussian：
  - 继续走 fog/free-space gate；
  - 在早期和中期直接 no-growth；
  - 后期放宽但仍受 free-space cap 和 pruning 约束。

配置入口：

```yaml
model.Background.ctrl.surface_guided_densification.supported_highlight_geometry
model.Background.ctrl.surface_guided_densification.fog_hard_gate_schedule[*].unsupported_highlight_*
```

新增 schedule 字段：

```yaml
unsupported_highlight_no_growth
unsupported_highlight_opacity_max
```

语义：

```text
可信表面高亮可以细化；
不可信高亮和自由空间高亮不能向空气扩散；
flare 由 camera-space 模块负责，不需要 3D 几何恢复。
```
