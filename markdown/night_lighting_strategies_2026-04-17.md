# 当前项目黑夜光照新增策略（一句话版）

- `PBR 分解渲染`：将高斯颜色从单一 SH 拟合升级为 `Diffuse + ASG Specular + Tone Mapping`，把夜间高动态范围亮度用显式物理项解释而非几何硬拟合。
- `Emissive 发光通道`：为高斯增加可学习发光颜色与强度参数，让车灯/灯牌等主动光源由独立发光分支承担能量。
- `各向异性发光 SH`：用低阶 SH 建模视角相关的方向性发光，使夜间强光在不同观察方向下呈现可控的角度响应。
- `发光锥先验`：通过 `emissive_cone_prior` 抑制主轴外过强辐射，限制强光能量在物理上更合理的方向锥内分布。
- `光源几何约束`：对高发光高斯施加尺度裁剪与表面支持/聚类正则，避免“靠膨胀体积凑亮度”的雾团化光源。
- `时变全局光照`：使用 `GlobalLightingModule` 按时间与相机嵌入预测全局 SH 光照系数，让夜景整体照明随时序和视角变化。
- `环境光立方贴图`：引入 `EnvLight` 作为远场天空/环境光补充，增强夜景背景光的连续性与稳定性。
- `亮区像素重加权`：在 RGB 损失中对高亮区域和后视相机做差异化权重，降低过曝区域对训练梯度的劫持效应。
- `高亮几何抑制`：对高亮区域额外惩罚 opacity，明确阻止模型用高密度几何去吸收强光误差。
- `Free-Space 约束`：当预测深度侵入可见空域时按 opacity 加权惩罚，直接压制夜间空气中伪密度生成。
- `后视伪深度补强`：在后视 LiDAR 稀疏区域引入单目深度伪监督并按梯度置信度衰减权重，提升黑夜后向空域约束覆盖率。
- `Floater 检测与自适应剪枝`：基于梯度/透明度/孤立度/表面距离打分识别漂浮高斯，并通过软削弱与硬删除分阶段清理雾状伪点。
- `表面引导增密`：在 split/dup 时结合亮点掩码、自由空间掩码与表面距离门控，优先在真实表面补点而非在空域扩增。
- `防雾硬门控调度`：通过分阶段 `fog_hard_gate_schedule` 动态收紧或放开增密预算，把训练前中期重点放在“先稳结构、后修外观”。
- `深度一致性与空间稀疏正则`：联合深度一致性与体素稀疏约束把高斯拉回可解释几何表面，抑制夜间光照下的无效体积堆积。
